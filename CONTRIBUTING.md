# Contributing to Elecar

Thanks for helping improve this project! 🚘

## Getting started
1. Fork the repo and clone your fork.
2. Create a branch: `git checkout -b feature/your-feature`.
3. Open `index.html` in a browser (or use a local server) and make your changes.

## Guidelines
- Keep it dependency-light: plain HTML, CSS and vanilla JavaScript.
- Follow the existing **BEM-style** class naming (`block__element`).
- Keep the layout **mobile-first**; add larger-screen rules inside `min-width` media queries.
- Keep keyboard focus, `aria-label`s on icon-only controls and reduced-motion support working.
- Test at roughly 340px, 768px and 1280px widths.

## Commit messages
Use short, conventional messages: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`.

## Pull requests
Describe what changed and why, and attach a screenshot for visual changes.
